## Uso pela equipe e pelos assistentes

1. Ler o card e seus critérios de aceite, DoR e DoD antes de preencher.
2. Abrir o documento indicado no comentário do card. Usar este índice ou o [índice em JSON](INDICE-DOCUMENTOS.json) para localizar os demais materiais.
3. Preencher a versão existente no Drive, preservando o modelo e os registros anteriores. Registrar apenas atividades efetivamente realizadas; um modelo criado não significa que a US foi concluída.
4. Salvar roteiros e evidências da Sprint 4 em [sprint-4/testes/](sprint-4/testes/README.md), vinculando a chave GK correspondente.
5. Exportar a versão atualizada para o mesmo caminho no repositório e abrir um PR com a chave do card. Conferir os links do Jira e a revisão de outro integrante.
